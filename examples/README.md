# Sample report

fabricated data (see the generation script in the project history / repo
notes) purely to show what the HTML dashboard looks like. `Acme Corp`,
the targets, and every number in here are made up — this is not a real
engagement or real findings.

Open `report.html` in a browser to see the actual rendered design,
including the hash-chain audit trail visualization.
